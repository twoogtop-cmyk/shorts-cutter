# Shorts Cutter

Сервис автоматической нарезки вертикальных Shorts из длинных видео: серий сериалов,
фильмов, подкастов. Загружаете серию — получаете готовые ролики 9:16 с субтитрами
и баннером, просматриваете и скачиваете подходящие.

Ищет моменты не механически «каждые 30 секунд», а по смыслу: распознаёт речь,
отдаёт диалоги языковой модели и отбирает законченные сцены с внятным началом и финалом.

## Что умеет

- Загрузка больших файлов кусками с докачкой после обрыва связи
- Распознавание речи с пословными таймкодами и разделением говорящих
- Поиск интересных моментов по диалогам: 5 оценок, категория, обоснование выбора
- Поиск экшен-сцен по плотности монтажа и громкости — то, что не видно в тексте
- Границы ролика привязываются к репликам и монтажным склейкам: фраза не обрывается
- Кадрирование 16:9 → 9:16 тремя способами: слежение за лицами, размытый фон, по центру
- Субтитры с подсветкой произносимого слова, в безопасной зоне интерфейса YouTube
- Баннер сверху отдельной полосой или поверх видео
- Финальная плашка с текстом — встаёт туда, где не закроет лицо
- Просмотр транскрипции с переходом по клику, полнотекстовый поиск по репликам
- Модерация с клавиатуры, редактор границ, массовые действия
- Скачивание одного ролика или архивом, полная очистка диска одной кнопкой

## Как работает

```
видео → аудио → распознавание речи → транскрипция с таймкодами
                                              ↓
                    детекция монтажных склеек → анализ моделью
                                              ↓
                                     моменты с оценками
                                              ↓
                              дешёвые превью для просмотра
                                              ↓
                                    отбор человеком
                                              ↓
                       финальный рендер 1080×1920 одним проходом ffmpeg
```

Ключевой принцип: ffmpeg делает всю работу с видео, но **не решает, что резать**.
Он не умеет распознавать речь и не понимает, где интересно. Смысл выбирает модель
по тексту диалогов, а громкость и частота склеек помогают найти сцены без слов.

Второй принцип: **одно кодирование**. Обрезка, кадрирование, субтитры, баннер и
плашка собираются в один проход, без промежуточных перекодирований.

## Стек

| Слой | Решение | Почему |
|---|---|---|
| Backend | Python + FastAPI | нативная работа с ffmpeg и OpenCV |
| БД | SQLite (WAL) + FTS5 | один файл, полнотекстовый поиск из коробки |
| Очередь | таблица в SQLite + worker-процесс | Redis с Celery не нужен для последовательной нагрузки |
| Frontend | React + Vite + Tailwind | собирается в статику, серверу не нужен Node |
| Видео | ffmpeg, ffprobe | |
| Лица | OpenCV DNN (res10 SSD) | без torch: 57 мс на кадр на одном ядре |
| Речь и AI | [gen-api.ru](https://gen-api.ru) | ElevenLabs Scribe и Claude через один API |

Стек выбран под слабый сервер: **1 ядро, 1 ГБ RAM, без GPU**. Docker, PostgreSQL,
Redis, MinIO и Next.js в SSR-режиме туда не помещаются. API занимает ~50 МБ памяти,
worker в простое ~10 МБ.

## Установка

Нужен сервер с Ubuntu, доступ по SSH и ключ (пароль в скриптах не хранится).

```bash
# на сервере
apt install -y ffmpeg nginx python3-venv python3-opencv sqlite3 zip
mkdir -p /opt/shorts-cutter /var/lib/shorts-cutter /etc/shorts-cutter
python3 -m venv --system-site-packages /opt/shorts-cutter/venv
/opt/shorts-cutter/venv/bin/pip install -r requirements.txt

# модель распознавания лиц
mkdir -p /opt/shorts-cutter/models && cd /opt/shorts-cutter/models
curl -sLO https://raw.githubusercontent.com/opencv/opencv/master/samples/dnn/face_detector/deploy.prototxt
curl -sL -o res10.caffemodel https://raw.githubusercontent.com/opencv/opencv_3rdparty/dnn_samples_face_detector_20170830/res10_300x300_ssd_iter_140000.caffemodel

# токен API — только здесь, в репозиторий не попадает
cat > /etc/shorts-cutter/env <<EOF
GENAPI_TOKEN=ваш-токен
SC_DATA_DIR=/var/lib/shorts-cutter
PYTHONUNBUFFERED=1
EOF
chmod 600 /etc/shorts-cutter/env
```

Конфигурация nginx и юниты systemd — в каталоге `deploy/`. Swap обязателен, если
памяти меньше 2 ГБ: под нагрузкой ffmpeg и OpenCV работают одновременно.

Деплой с локальной машины (фронтенд собирается на ней, на сервер уезжает статика):

```bash
export SC_SERVER=root@ваш-сервер
cd web && npm install && npm run build && cd ..
./deploy.sh
```

## Стоимость обработки

Распознавание речи и анализ — платные внешние сервисы. Ориентир на час видео:

```
распознавание речи   ~120 ₽   (тарифицируется по минутам)
анализ диалогов       ~20 ₽
поиск экшен-сцен       ~3 ₽
рендер                   0     (ffmpeg на своём сервере)
```

Транскрипция сохраняется в базе: повторный поиск моментов с другими настройками
стоит только цену анализа, распознавание заново не оплачивается.

## Производительность на одном ядре

Замеры на серии 54 минуты, 675 МБ, 1920×1080:

| Операция | Время |
|---|---|
| Извлечение аудио | 20 сек |
| Распознавание речи (внешний сервис) | ~2 мин |
| Детекция монтажных склеек | ~7 мин |
| Анализ диалогов | ~1 мин |
| Превью 540×960 | ~70 сек на ролик |
| Финал 1080×1920, CRF 18 | ~3 мин на ролик |

## Структура

```
server/app/
  main.py          точка входа, состояние системы, настройки, очистка
  db.py            схема, миграции, настройки
  worker.py        цикл обработки очереди
  tasks.py         обработчики: probe, транскрипция, анализ, рендер
  routes/          videos, jobs, candidates, transcript, banners
  services/
    ffmpeg.py      обёртки ffmpeg/ffprobe, прогресс, отмена
    stt.py         распознавание речи, сборка реплик из слов
    analysis.py    поиск моментов моделью, оценки, дедупликация
    action.py      экшен-сцены по монтажу и громкости
    faces.py       слежение за лицами, траектория кадрирования
    subtitles.py   генерация ASS
    render.py      сборка вертикального ролика одним проходом
    queue.py       очередь на SQLite
web/src/           интерфейс: главная, шортсы, транскрипция, баннеры, настройки
deploy/            nginx и systemd
```

## Ограничения

- Рассчитан на одного пользователя, авторизации нет — не открывайте сервис в интернет
  без reverse proxy с паролем
- Обрабатывает одну серию за раз: на диске должны поместиться исходник, аудио,
  превью и рендеры
- Финальный рендер на одном ядре медленный; при большом потоке нужен сервер мощнее
- Распознавание речи требует внешнего API; локальный Whisper на 1 ГБ RAM не работает
